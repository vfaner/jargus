# 百目 JArgus v2.0.7

安全与稳定性修复版本，并改进「检查更新」：针对符号链接、路径穿越、Webhook 验签、分页参数与登录跳转等 9 类问题做了收紧；检查更新改为 GitHub 为主、Gitee 自动兜底，并识别同版本号安装包重发。

## 本次更新

### 检查更新

- **双源兜底**：GitHub 不可达或限流时自动改查 Gitee，设置页主栏标注来源（GitHub/Gitee）。
- **同版本安装包重发提醒**：版本号相同但远端 jar 与本机不同（依次比较 SHA-256、附件大小、HEAD `Content-Length`）时，提示「同一版本号的安装包已重新发布」，可选择「忽略此提示」；发布方再次上传新文件后会重新提醒。
- **管理员导航提示**：检测到新版本或安装包重发时，设置入口显示圆点；进入设置页会强制刷新一次检查结果。
- **发布说明链接过滤**：渲染远端发布说明时只保留安全协议，`javascript:` 等链接会被剥离。

### 安全加固

- **符号链接不再被跟随**：快照复制与 Java 文件扫描跳过符号链接，避免仓库内指向本机任意文件的链接把 `~/.ssh/id_rsa` 等敏感文件读入快照，随评审结果或问题上下文外泄。
- **问题上下文读取限制在快照目录内**：读取源码前统一归一化路径并校验必须位于快照根目录之下，历史或异常数据中的 `../`、绝对路径不再能读到服务器任意文件。
- **CI Webhook 验签按原始字节计算**：GitHub HMAC 直接对请求体原始字节校验，不再先转字符串再按 UTF-8 取字节，非 ASCII 或非 UTF-8 请求体的签名结果恢复正确。
- **`/api/**` 不再享受静态资源后缀白名单**：认证过滤器只对真正的静态资源按 `.js/.css/.png` 等后缀放行，杜绝接口因后缀碰巧相同而免登录。
- **登录回跳地址校验加严**：`redirect` 参数用 URL 解析后比对同源并只回跳 path/query/hash，`/\evil.com` 这类会被浏览器归一化成外站地址的写法不再生效。

### 稳定性修复

- **分页参数收敛**：页码下限 1、每页条数上限 200，覆盖任务、问题、CI 触发器/记录、令牌、收件人、发件配置、评审规则与忽略规则列表，避免 `size` 传入超大值导致全表加载进内存。
- **单元测试超时结束整棵进程树**：超时后连同 mvn/gradle 派生的 surefire JVM、Gradle daemon 一并结束，不再残留孤儿进程持续占用 CPU。
- **驱动上传关闭输入流**：上传 JDBC 驱动后显式关闭文件流，反复上传不再泄漏文件句柄。
- **远端登录参数错误返回 400**：`configId` 不是数字时返回参数错误，不再落到全局异常处理器变成 500。

## 升级须知

- 新增 `update_artifact_dismissal` 表用于记住「忽略安装包提示」，旧库首次启动自动补建，直接覆盖 jar 即可；加密密钥、Cookie、CI Token 与 v2.0.0 起的版本一致。
- 检查更新配置：`app.update-check.enabled`（默认 `true`）、`app.update-check.timeout-ms`（默认 `5000`）、`app.update-check.match-artifact`（默认 `true`）。
- 列表接口的 `size` 超过 200 时按 200 处理；页面默认每页 20/50/100，不受影响。
- 使用 CI Webhook 的仓库无需改动配置，验签逻辑对合法请求完全兼容。
